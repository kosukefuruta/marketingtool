# Owtell SEO診断ツール 競合機能調査

調査日: 2026-09-21  
対象: 国内外のSEO診断・運用支援サービス 12製品  
関連資料: [プロダクト企画](product-plan.md)、[目標駆動型SEO施策エンジン構想](goal-driven-action-planning.md)、[有料機能要件定義](paid-feature-requirements.md)

## 1. 調査の目的

Owtell SEO診断ツールの次期企画を検討するため、競合製品が提供する価値を次の観点で比較する。

- 技術SEO・サイト診断
- 順位、検索流入、競合、被リンクの調査
- 継続監視と変化検知
- コンテンツ企画、作成、改善
- AI検索（GEO / AIO / LLMO）への対応
- 改善作業の優先順位付けと実行管理
- レポート、共有、外部連携
- 価格と主な対象顧客

公開情報だけでは確認できない仕様は推測せず「非公開」または「確認できず」とした。価格は契約期間、税、通貨、キャンペーン、地域によって変わるため、意思決定時には各社へ再確認する。

## 2. エグゼクティブサマリー

競合は大きく5群に分かれる。

| 分類 | 主な製品 | 中心価値 | Owtellとの関係 |
|---|---|---|---|
| 総合SEOプラットフォーム | Ahrefs、Semrush、SE Ranking、Ubersuggest | 診断、順位、キーワード、競合、被リンクを一体化 | データ量や機能数では競争しない。統合された導線は参考になる |
| 技術監査特化 | Screaming Frog、Sitechecker | 大規模クロール、技術的問題、定期監視 | Owtellの診断精度、差分、説明設計の直接的な比較対象 |
| 国産コンテンツSEO | ミエルカSEO、パスカル、EmmaTools | 検索意図、上位比較、記事制作・改善、日本語サポート | 日本語での分かりやすさ、具体的な修正案が重要な比較対象 |
| 順位計測特化 | Nobilista | 安価なクラウド順位計測 | 月額2,000円前後の継続利用価値を示す隣接競合 |
| 無料の一次データ・診断 | Google Search Console、PageSpeed Insights / Lighthouse | Google検索実績、インデックス、速度・品質評価 | 置き換えるのではなく、データを解釈し行動につなげる対象 |

市場では「問題を見つける」機能は既に豊富で、無料でも利用できる。一方、問題を小規模事業者が実行可能な作業へ変換し、実施日、修正内容、検索実績の変化まで一つの流れで管理する機能は、総合ツールでも中心に据えられていない。

したがってOwtellの主戦場は、診断項目数や巨大な独自データベースではなく、次の一連の体験に置くのが妥当である。

> 発見 → 理解 → 優先順位付け → 実施記録 → 再診断 → Search Consoleによる効果確認

## 4. 製品別の詳細

### 4.1 Sitechecker

#### 位置付け

クラウド型のサイト監査、順位計測、サイト変更監視を統合した製品。技術SEOの問題一覧を提示するだけでなく、Search ConsoleやGoogle Analytics 4の実績とページ単位で結び付ける点が強い。

#### 主な機能

- サイト全体をクロールし、100以上の技術SEO・オンページ問題を検出する
- 内部・外部リンク切れ、リダイレクト、重複・薄いコンテンツ、タイトルや見出し、画像、robots、構造化データ、速度などを確認する
- 問題を重要度別に分類し、理由と修正方法を示す
- ページ詳細でコンテンツ、画像、リンク、SERPプレビュー、モバイル・デスクトップ速度をまとめて確認できる
- Site Monitoringでページ内容や技術要素の変更を検出する
- Rank Tracker、Backlink Tracker、キーワード調査、AI Visibilityを備える
- Search Consoleのクリック、表示回数、CTR、平均掲載順位、クエリをページに統合する
- 新規・消失ページや、検索流入を獲得・喪失したページを比較できる
- PDF、CSV、Google Sheetsへの出力、ホワイトラベル、共有、APIを提供する
- APIでは監査結果、ページ詳細、セグメント、変更履歴、GSC、GA4、順位、AI Visibilityなどを取得できる

#### 価格・制約

- Basic: 月額99米ドル（年払いの月額換算83米ドル）
- Standard: 月額249米ドル（年払いの月額換算208米ドル）
- Premium: 月額449米ドル（年払いの月額換算375米ドル）
- Enterprise: 要問い合わせ
- プランによりサイト数、監査ページ数、監視頻度、キーワード数が異なる。無料トライアルあり

#### Owtellへの示唆

ページごとの診断、GSC実績、変更履歴を同じ文脈で見せる設計は参考になる。一方、Owtellは多数のグラフやツールを並べず、「今やること」と「実施後の変化」に画面を絞る余地がある。

出典: [Site Audit](https://help.sitechecker.pro/article/70-how-to-use-site-audit)、[ツール一覧](https://help.sitechecker.pro/category/150-our-tools)、[API](https://docs.sitechecker.pro/guides/getting-started/)、[料金](https://sitechecker.pro/account/plans/)

### 4.2 SE Ranking

#### 位置付け

順位計測を核に、サイト監査、競合・キーワード・被リンク調査、コンテンツ、ローカルSEO、AI検索可視性まで統合するクラウド型プラットフォーム。代理店向けのレポート・ホワイトラベルも強い。

#### 主な機能

- 国、地域、端末、検索エンジンを指定した順位計測
- キーワード調査、競合の自然検索・広告調査
- 被リンク分析と新規・消失リンク監視
- 技術、セキュリティ、表示速度、HTTP、リダイレクト、インデックス、メタ情報、リンクなどのサイト監査
- 問題ごとの説明と解決方法、監査スコア、再クロール
- On-Page SEO CheckerとContent Editorによるページ・記事改善
- Local Marketingによるローカル順位、ビジネスリスティング、レビュー管理
- Page Changes Monitoringでタイトル、description、H1/H2、本文、リンク、robots、canonical、HTTP状態などを監視
- 自社だけでなく競合ページも監視でき、日次、3日ごと、週次、月次、任意頻度に対応する
- AI Search機能でAI回答内のブランド露出、引用、競合、プロンプトを追跡する
- GA4、Search Consoleなどと連携し、レポート、ゲストリンク、ホワイトラベルを提供する

#### 価格・制約

- Core: 月額129米ドル、年払いの月額換算103.20米ドル。10プロジェクト、2,000キーワード、月250,000監査ページなど
- Growth: 月額279米ドル、年払いの月額換算223.20米ドル。30プロジェクト、5,000キーワード、月2,000,000監査ページ、ページ変更監視など
- Enterprise: 個別見積もり
- 14日間トライアルあり。カード登録不要と案内されている

#### Owtellへの示唆

ページ変更監視の粒度と通知は有料版の将来機能として有用。ただしOwtellの価格帯で常時監視を広げるとコストが合わないため、診断時の差分と重要ページ限定の監視から始めるべきである。

出典: [製品概要](https://help.seranking.com/hc/en-us/articles/30203777895068-What-is-SE-Ranking)、[Website Audit](https://help.seranking.com/hc/en-us/articles/16332618262044-How-to-use-Website-Audit)、[Page Changes Monitoring](https://help.seranking.com/hc/en-us/articles/16332537550108-Page-Changes-Monitoring-Overview)、[料金](https://seranking.com/subscription.html)

### 4.3 Ubersuggest

#### 位置付け

初心者にも扱いやすい総合SEOツール。キーワード・競合調査とコンテンツ案を中心に、サイト監査、順位、被リンク、AIライティングを低価格でまとめている。

#### 主な機能

- キーワード候補、検索ボリューム、難易度、CPC、関連語、コンテンツ案の調査
- 競合サイトの推定流入、上位ページ、流入キーワード、被リンクの分析
- プロジェクト単位の順位計測、競合追跡、サイト状態のダッシュボード
- ドメイン全体または単一URLのSite Audit
- 重大なエラー、警告、推奨事項に分け、重複、文字数不足、リダイレクト、リンク、メタ情報、速度などを検査する
- SEO Opportunitiesで影響と難易度を基に改善候補をカード化する
- 推奨事項を完了扱いにし、フィードバックを送れる
- AI Writerでタイトル、構成、本文作成や既存記事の最適化を支援する
- AI Search Visibilityで生成AI上の言及、引用、競合状況を表示する
- PDF出力などの共有機能を提供する

#### 価格・制約

- Individual: 月額29米ドル。1プロジェクト、1ドメイン1,000ページ、125追跡キーワード、競合5件など
- Business: 月額49米ドル。7プロジェクト、1ドメイン5,000ページ、150追跡キーワード、競合10件など
- Enterprise / Agency: 月額99米ドル。15プロジェクトなど
- 7日間トライアルあり。買い切りプランが期間限定で提示される場合がある

#### Owtellへの示唆

改善候補を影響・難易度で並べ、専門家でなくても選びやすくする設計は重要。Owtellではさらに、完了ボタンだけでなく、修正前後、実施日、28日後の効果測定までつなげることで差別化できる。

出典: [全機能ガイド](https://ubersuggest.zendesk.com/hc/en-us/articles/42466802160283-Complete-Guide-to-All-Ubersuggest-Features)、[Project Dashboard](https://ubersuggest.zendesk.com/hc/en-us/articles/4405442920731-Getting-to-Know-Your-Project-Dashboard)、[SEO Opportunities](https://ubersuggest.zendesk.com/hc/en-us/articles/22109330872219-SEO-Suggestions-Top-Seo-Opportunities)、[料金](https://app.neilpatel.com/ja/pricing/)

### 4.4 Ahrefs

#### 位置付け

独自の検索・被リンクデータベースを核にした専門家向け総合SEOプラットフォーム。Site Audit単体も高機能で、大規模サイトの問題発見、絞り込み、履歴比較に強い。

#### 主な機能

- 170以上の技術SEO・オンページ問題を検出するSite Audit
- Health Scoreと、問題種別・重要度・URL数・推移のダッシュボード
- Core Web Vitals、HTML/CSSサイズ、タイトル、meta、H1、重複、indexability、リンク、リダイレクト、画像、JavaScript、robots、sitemap、構造化データ、多言語などを監査する
- クロール速度、範囲、URLルール、認証、JavaScriptレンダリング、ユーザーエージェントなどを設定できる
- 過去クロールとの比較、カスタム課題、URLセグメント、高度なフィルターを提供する
- 生HTML、レンダリング後HTML、本文を検索でき、CSVやZIPで出力できる
- Site Explorerで自然検索キーワード、推定流入、競合、被リンク、リンク切れなどを調査する
- Keywords Explorer、Rank Tracker、Content Explorer、Web Analytics、AI関連機能を備える
- ポートフォリオ、アラート、レポート、APIに対応する
- 所有確認済みサイトはAhrefs Webmaster Toolsで無料利用でき、月5,000クロールクレジットが付く

#### 価格・制約

- Free / Webmaster Tools: 所有確認サイト向けの限定機能
- Starter: 月額29米ドル
- Lite: 月額129米ドル
- Standard: 月額249米ドル
- Advanced: 月額449米ドル
- Enterprise: 月額1,499米ドルから
- Site Auditの履歴保持は公式ヘルプ上で12か月。プラン、クレジット、利用者追加に制限がある

#### Owtellへの示唆

監査の網羅性では追随しない。Owtellでは主要な問題を確実に検出し、Ahrefsでは利用者自身が行うフィルター・解釈・タスク化を自動化する方が価値を出しやすい。

出典: [Site Audit](https://ahrefs.com/site-audit)、[Site Auditヘルプ](https://help.ahrefs.com/en/collections/87920-site-audit)、[Ahrefs Webmaster Tools](https://ahrefs.com/webmaster-tools)、[料金](https://ahrefs.com/pricing)

### 4.5 Semrush

#### 位置付け

SEOだけでなく、広告、コンテンツ、ローカル、ソーシャル、AI検索までカバーするマーケティングプラットフォーム。企業や代理店が複数チャネルを横断管理する用途に強い。

#### 主な機能

- 140以上のチェックを行うSite Audit
- クロール可能性、HTTPS、内部リンク、国際SEO、マークアップ、Core Web Vitals、JavaScriptなどを検査する
- エラー、警告、通知とテーマ別レポート、Site Health、修正方法を提供する
- クロール比較、定期実行、メール通知、Trelo連携、CSV出力
- Position Tracking、Organic Research、Keyword Gap、Keyword Magic Toolによる順位・競合・キーワード調査
- Backlink Analytics、Backlink Audit、Link Building Tool
- SEO Writing Assistant、ContentShake AIなどによる記事企画・作成・最適化
- AI VisibilityでChatGPT、Google AI、Gemini等におけるブランド露出、競合、引用を分析する
- Google Analytics、Search Consoleなどとの統合
- My Reportsで複数ツールのデータをPDF化し、定期配信・ブランド変更できる
- チーム、CRM、クライアントポータル、APIなど代理店・組織向け機能を提供する

#### 価格・制約

2026年9月に表示された地域別ページでは次のユーロ価格だった。地域により米ドル等へ変わる。

- Starter: 月額190ユーロ、年払いの月額換算158.40ユーロ
- Pro+: 月額286ユーロ、年払いの月額換算238ユーロ
- Advanced: 月額526ユーロ、年払いの月額換算436.99ユーロ

PC上で動作するクローラー。細かなクロール制御、抽出、検証、エクスポートが強く、技術SEO担当者や開発者が詳細調査に使う。クラウドSaaSのような継続運用画面は中心ではない。

- XML Sitemapの生成・検証、robots.txtの確認・カスタム設定
- 構造化データ、AMP、hreflang、アクセシビリティ、スペル・文法の検証
- CSS selector、XPath、正規表現によるカスタム抽出

- Google Analytics、Search Console、PageSpeed Insightsとの連携
- OpenAI、Geminiなどを利用した分類・生成処理
- クロール保存、比較、スケジュール実行、CLI、自動エクスポート
- クロール図、ディレクトリツリーなどの可視化

#### 価格・制約

- 5ライセンス以上は数量割引あり

#### Owtellへの示唆

検査エンジンのテスト項目やクロール制御のベンチマークとして使える。しかし画面は専門家向けであるため、Owtellは設定の少なさ、問題の統合、平易な日本語、実行管理で明確に住み分けられる。

## 5. 競合から見える共通機能パターン

### 5.1 診断結果は「重要度」と「直し方」をセットにする

主要な監査製品は、問題名だけでなく、重大度、影響URL、原因、推奨修正をセットで表示する。Owtellも診断ルールごとに最低限、次を構造化して保持する必要がある。

- 問題の短い名称
- SEOや利用者への影響
- 判定根拠と実測値
- 対象URL
- 修正手順
- 技術担当者へ渡せる具体例
- 優先度と、その算出理由

### 5.2 スコアより「前回から何が変わったか」が継続利用を生む

Sitechecker、SE Ranking、Ahrefs、Semrushは定期クロールや比較を持ち、Nobilistaは日々の順位変化を価値にしている。単発スコアだけでは再訪理由が弱いため、Owtellでは次を優先する。

- 新しく発生した問題
- 解消した問題
- 悪化・改善したページ
- ユーザーが実施した施策と一致する変化
- 何も変わらなかった場合の明確な通知

### 5.3 総合ツールは機能が豊富だが、判断負荷も大きい

Ahrefs、Semrush、SE Rankingは高機能だが、利用者が目的に応じてツール、条件、指標を選ぶ必要がある。Owtellの対象利用者には、分析画面を増やすより次の1アクションを示す方が適する。

### 5.4 国産製品は「日本語支援」と「コンテンツ」が強い

ミエルカ、パスカル、EmmaToolsは、日本語の記事作成、検索意図、上位比較、サポートを中心に価値を作っている。Owtellでも説明文や修正例の日本語品質は、診断項目数と同等以上に重要である。

### 5.5 AI検索の可視化が標準機能になりつつある

Semrush、SE Ranking、Sitechecker、Ubersuggest、ミエルカ、パスカルは、生成AI回答でのブランド露出・引用・競合比較を提供または強化している。ただし、Owtellの初期顧客にとって従来検索の基礎改善より優先度が高いとは限らない。

## 6. Owtellの機能方針案

### 6.1 優先度A: 中心価値として早期に完成させる

1. **診断結果から施策を作成**
   - 問題を一括で施策へ変換する
   - 同じ原因のURLをまとめる
   - 期待効果、難易度、対象ページ数から優先度を付ける

2. **施策の実行記録**
   - 未着手、対応中、実施済み、見送り
   - 修正前、修正後、実施日、メモ
   - 施策詳細から元の診断根拠へ戻れる

3. **診断差分**
   - 新規、継続、解消、再発を分ける
   - スコアだけでなくURLと問題の差分を保存する
   - 施策実施後の初回診断を分かりやすく示す

4. **Search Console効果測定**
   - 実施前28日と実施後28日を基本比較にする
   - 56日、90日も後追いする
   - クリック、表示回数、CTR、平均掲載順位を施策・URL単位で表示する
   - 因果関係を断定せず「実施後に観測された変化」と表現する

5. **行動中心のダッシュボード**
   - 今日・今週やること
   - 重大な新規問題
   - 対応中の施策
   - 効果測定時期を迎えた施策
   - 改善または悪化した施策

6. **初心者向けの日本語説明**
   - 専門用語の説明
   - CMSに依存しない基本手順
   - 修正例と確認方法
   - 対応しなくてもよい例、開発者へ依頼すべき例

### 6.2 優先度B: 継続率を上げる次期機能

- 月次サマリーのアプリ内表示とメール送信
- 重要ページを指定した軽量な変更監視
- 問題・施策の担当者、期限、リマインド
- CSVエクスポートと共有用の読み取り専用ページ
- PageSpeed Insights連携と速度指標の履歴
- Search Consoleから機会を自動抽出
  - 表示回数は多いがCTRが低いページ
  - 4〜20位で改善余地があるクエリ・ページ
  - 前期間からクリックが大きく低下したページ
  - 意図しないURLが同一クエリで競合する可能性
- WordPressなど主要CMS別の修正ガイド

### 6.3 優先度C: 需要検証後の拡張

- 複数サイト、複数ユーザー、担当・権限
- PDF、会社ロゴ、代理店向け共有・定期レポート
- 検索意図・上位コンテンツ比較
- 記事構成やリライト案のAI支援
- AI検索でのブランド露出・引用監視
- GA4連携によるコンバージョンとの関連確認
- CMS連携による修正候補の下書き作成

### 6.4 当面は実装しないもの

- 独自の大規模被リンクデータベース
- 独自の検索ボリューム・競合流入データベース
- 大量キーワードの日次順位取得
- AIによる記事の全自動量産
- 高度な広告、SNS、ローカルリスティング管理
- 何百項目もの専門家向けクロール設定

これらは開発・データ取得コストが高く、既存大手の優位性が強い。必要になった場合も外部APIや連携を先に検討する。
