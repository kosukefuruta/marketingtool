## 問題発生時に保存する情報

- 操作した時刻（日本時間）
- 対象画面と操作内容
- ブラウザに表示された文言
- Koyebログの該当部分
- Stripe Event IDまたはRequest ID
- SESのMessage ID（確認できる場合）

メールアドレス、OTP、カード情報、APIキー、Webhook署名シークレット、DB接続文字列は記録・共有しない。

メールが届かないときは、必ずKoyebのログで`[mail]`を確認する。Better Authは送信をバックグラウンドタスクで実行するため、送信に失敗しても画面は成功表示になる。
