# Owtell SEO診断ツール プロダクト企画

最終更新: 2026-09-20

## 1. 目的

Owtell SEO診断ツールを、SEO専任者を置きにくい中小企業・個人事業主向けのサービスとして提供する。

対象ユーザーは、高価で多機能なSEOツールを使いこなすことよりも、次のことを簡単に把握したい事業者とする。

- 自社サイトのどこに問題があるか
- 次に何を修正すべきか
- その修正を実施したか
- 修正後に検索流入がどう変化したか

有料版の想定価格は月額1,980円（税込）前後とする。

## 2. プロダクトの位置付け

単発の技術SEO診断だけでは、無料で利用できる既存サービスとの差別化が難しい。そのため、有料版の中心価値を「診断項目の多さ」ではなく、SEO施策の実行管理と効果測定に置く。

プロダクトの価値は次のように分ける。

- 無料版: 現在の問題と修正候補が分かる
- 有料版: 何を修正し、実施後にどう変化したかを継続して管理できる

有料版は、SEO分析の専門家向けツールではなく、小規模事業者向けの「SEO施策管理台帳」として設計する。

## 3. 競合調査

### Ahrefs Free

- 所有確認したサイトを無料で登録できる
- Site Auditで月5,000クロールクレジットを利用できる
- 170以上の技術SEO・オンページSEO上の問題を診断する
- 被リンクや流入キーワードの情報も提供する

参考: [Ahrefs Free](https://ahrefs.com/webmaster-tools)

単純な診断項目数や無料巡回ページ数では競争しない。

### Screaming Frog SEO Spider

- 1回500 URLまで無料で巡回できる
- タイトル、メタ情報、リンク切れ、重複ページなどを詳細に調査できる
- 有料版は年額199ポンド
- デスクトップアプリであり、主にSEO担当者や技術者向けである

参考: [Screaming Frogの料金と機能](https://www.screamingfrog.co.uk/seo-spider/pricing/)

Owtellでは設定項目を増やすより、結果の理解しやすさと次の行動を重視する。

### Semrush

- SEO Toolkit Proは月額139.95米ドルから
- サイト診断、順位計測、キーワード調査、競合分析、被リンク分析などを提供する
- Proでは5サイト、500キーワードの日次計測、月100,000ページの診断が可能

参考: [Semrush SEO Toolkitの料金](https://www.semrush.com/kb/1547-seo-toolkit-pricing-and-plans)

総合SEOプラットフォームとして正面から競争しない。

### SE Ranking

- Coreプランは月額129米ドルから
- 順位計測、競合・キーワード調査、被リンク、サイト診断をまとめて提供する
- Coreでは10プロジェクト、2,000キーワード、月250,000ページの診断が可能

参考: [SE Rankingの料金](https://seranking.com/subscription.html)

大規模なデータ収集や代理店向け機能を初期の対象にしない。

### Nobilista

- 検索順位をクラウド上で自動計測する日本語サービス
- 150キーワードのパーソナルプランは月額990円（税込）
- 300キーワードのビジネスプランは月額1,860円（税込）

参考: [Nobilistaの料金](https://co.nobilista.com/ja/price/)

月額2,000円前後で検索順位を継続管理する需要は存在する。一方、Owtellは順位計測だけでなく、施策の記録と効果測定を中心にする。

### Google Search Console

- 自社サイトについて無料で利用できる
- 検索クエリやページごとの表示回数、クリック数、CTR、平均掲載順位を確認できる
- 国、端末、検索での見え方、日付などで分析できる

参考: [Search Console パフォーマンスレポート](https://support.google.com/webmasters/answer/7576553?hl=ja)

有料の検索順位APIを最初から導入せず、まずSearch Consoleの実績データを利用する。順位の絶対値だけではなく、表示回数、クリック数、CTRの変化を重視する。

### PageSpeed Insights

- ページのパフォーマンスを無料で測定できる
- Lighthouseのラボデータを取得し、改善候補を提示できる
- APIはキーなしでも利用できるが、継続的な自動利用ではAPIキーが推奨される

参考: [PageSpeed Insights API](https://developers.google.com/speed/docs/insights/v5/get-started)

速度測定そのものではなく、測定結果を施策として管理できることを差別化要素にする。

## 4. 市場の隙間

既存市場には、次の選択肢がある。

- 無料だが、利用者自身にSEO知識が必要な診断ツール
- 検索順位だけを継続記録する低価格ツール
- 多数の機能を備えた高価格な総合SEOツール

Owtellは、その間にある次の需要を狙う。

> 専門知識がなくても、自社サイトのどこを、なぜ、どう直し、その結果どう変わったかを管理できる日本語サービス

ユーザーに大量の問題一覧を見せるだけでなく、「次に実行する施策」へ変換することが重要である。

## 5. プラン案

### 無料版

- アカウント登録なしで利用可能
- 1回10ページまで診断
- ユーザーによる手動実行
- ページごとに診断項目、評価、詳細を表示
- 問題の理由と一般的な修正方法を表示
- 診断結果や施策の継続保存は行わない
- Search Consoleとは連携しない

無料版の強みは、巡回ページ数ではなく「URLを入力するだけですぐ使えること」と「日本語で結果を理解しやすいこと」とする。

### 有料版（想定月額1,980円・税込）

- 1サイトを登録可能
- 最大300ページを診断
- 月1回の定期診断
- ユーザーによる任意の再診断
- 診断履歴を12か月保存
- 前回診断との差分表示
- 施策の登録と進捗管理
- 修正前後の内容と実施日の記録
- Google Search Console連携
- 施策実施前後の効果測定
- リマインド通知
- 月次サマリー

ページ数、診断頻度、価格は仮説であり、提供コストと利用者へのヒアリングを基に決定する。

### 将来の上位版

月額4,980円前後を仮置きし、需要を確認してから検討する。

- 3サイト
- 最大1,000ページ
- より短い間隔での自動診断
- 複数ユーザー
- PDFレポート
- 会社ロゴ入りレポート
- クライアント向け共有URL
- WordPressなどCMS別の修正手順

## 6. 診断と施策管理の周期

SEO施策の効果は短期間では判断しにくいため、サイト全体を毎週診断することを有料価値の中心にはしない。

- サイト診断: 月1回、またはユーザーによる任意実行
- 施策の確認と作業記録: 随時。週ごとの運用も可能
- 効果測定: 実施日から28日後、56日後、90日後

毎週利用する理由は、サイトを毎回診断することではなく、施策の確認、作業状況の更新、測定時期を迎えた施策の確認に置く。

## 7. 施策管理

診断で見つかった問題は、対応可能な「施策」に変換する。診断結果から自動作成するほか、ユーザーが任意の施策を追加できるようにする。

### 施策の状態

1. 未着手
2. 対応中
3. 実施済み
4. 見送り

実施済みに変更するときは実施日を記録し、効果測定の起点にする。

### 施策に保存する情報

| 項目 | 内容 |
|---|---|
| 対象サイト | 施策を行うサイト |
| 対象ページ | 修正するURL。サイト全体の施策では任意 |
| 施策名 | タイトル修正、見出し追加、リンク切れ修正など |
| 修正理由 | 診断結果や検索実績から、対応が必要な理由を説明 |
| 優先度 | 高・中・低 |
| 状態 | 未着手・対応中・実施済み・見送り |
| 作成日 | 施策を登録した日 |
| 実施日 | 修正内容を公開した日 |
| 修正前 | 元のタイトル、文章、診断値など |
| 修正後 | 変更後の内容 |
| メモ | 担当者の作業記録 |
| 効果判定 | 改善・変化なし・悪化・判定待ち |

## 8. 効果測定

Search Consoleと連携し、施策実施日の前後で次の指標を比較する。

- 表示回数
- クリック数
- CTR
- 平均掲載順位

基本の比較期間は「実施前28日」と「実施後28日」とする。必要に応じて56日後、90日後にも再評価する。

表示例:

> 8月1日にタイトルを修正
> 修正前28日: 1,200表示、18クリック、CTR 1.5%
> 修正後28日: 1,350表示、32クリック、CTR 2.4%
> 判定: CTRが改善しています

検索結果は季節性、競合、Googleの変更、他の施策など複数の要因に影響される。そのため、施策だけが変化の原因だとは断定せず、「施策実施後に観測された変化」として表示する。

検索順位についても個別検索時の絶対順位とは扱わず、Search Consoleが記録する平均掲載順位の推移として扱う。

## 9. ダッシュボード

ログイン後の最初の画面では、次に取るべき行動が分かるようにする。

- 優先度が高い未着手の施策
- 今週対応する施策
- 対応中の施策
- 実施済みで効果測定を待っている施策
- 28日後などの測定時期を迎えた施策
- 検索実績が改善した施策
- 新しく発生した重大な問題

診断スコアだけを大きく見せるのではなく、作業と効果の状態を中心に構成する。

## 10. 初期段階で対象外とするもの

- 独自の被リンクデータベース
- 検索ボリュームデータベース
- 競合サイトの流入推定
- Google検索結果の定期的な直接スクレイピング
- 外部の有料検索順位APIへの依存
- 大量の記事自動生成
- 代理店向けの複雑な権限管理
- SEO専門家向けの多数の詳細設定

これらは取得・運用コストが大きく、既存の総合SEOツールとの直接競争になるため、初期版では扱わない。

## 11. 開発の優先順位案

最初に有料サービスとして利用できる基盤と、施策管理・効果測定を完成させる。この段階では、現行の診断項目をそのまま利用し、新しい診断項目や診断アルゴリズムは追加しない。

1. ユーザー登録とサイト登録
2. 有料決済と契約管理
3. Search Console連携
4. 施策の作成
5. 施策の状態、実施日、修正前後、メモの管理
6. 施策実施前後の効果測定
7. リマインドと月次サマリー
8. 現行診断結果のユーザーアカウントへの保存
9. 前回診断との差分
10. 月1回の定期診断

有料版の提供開始後、利用者が実際に登録する施策や要望を確認しながら、診断項目を優先度順に追加する。診断項目数を増やすこと自体はリリース条件にしない。

実装前に、対象となる中小企業・個人事業主へ画面案と価格を提示し、診断結果の保存よりも施策管理と効果測定に支払い意向があるか検証する。

## 12. プロダクトメッセージ案

> 無料版は、現在の問題が分かる。
> 有料版は、何を直し、その結果どう変わったかが分かる。

または、より直接的に次のように表現する。

> SEOの問題を見つけるだけでなく、修正と効果まで記録する。
